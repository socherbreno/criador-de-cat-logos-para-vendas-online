# ⚡BRS O Gerador de Catálogo Pro para E-commerce
Ferramenta de automação para gerar títulos e descrições otimizadas e persuasiva para e-commerce.
## 🚀 Funcionalidades
- Leitura automática de ficheiros de dados brutos.
- Criação de Títulos com técnicas de SEO (limite de 60 caracteres).
- Geração de descrições altamente persuasivas com *bullet points*.
- Exportação automática de um novo ficheiro Excel (.xlsx) já formatado, com quebra de texto e design profissional, pronto a ser utilizado.

## 🛠️ Tecnologias Utilizadas
- Python
- Streamlit
- Google Generative AI (Gemini 2.5 Flash)
- Pandas & XlsxWriter
